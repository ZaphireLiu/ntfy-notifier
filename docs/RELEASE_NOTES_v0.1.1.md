## ntfy-notifier v0.1.1

修复断线重连后重复弹出过时通知的问题。

### 修复

- **重连不再补弹旧消息**：新增 `notify.max_message_age`（默认 `5m`，设为 `0` 关闭）。重连时服务端补发的消息若超过该年龄，只推进续传游标、不弹 Toast，避免把几分钟前的消息当成新通知。
- **重启不再重复上一条**：最后一条已处理消息的 ID 记录到 `state.json`，启动时预热去重表，进程重启后的重放会被丢弃。
- **时钟偏差防护**：服务端时间戳若超前于本机，会被钳制到当前时间，避免 `lastSeen` 跳到未来导致后续消息永久漏收；已落盘的未来游标同样在读取时纠正。
- 托盘状态详情新增「过期」计数，便于确认过滤是否生效。

### 升级说明

- 直接替换 exe 即可，`config.toml` 无需改动。不写 `max_message_age` 时默认为 `5m`。
- 若希望恢复旧行为（补发的消息一律弹窗），在 `[notify]` 下设置 `max_message_age = "0"`。
- `state.json` 会新增 `lastId` 字段，向前兼容旧文件。

### 已知限制

- 未签名 exe，首次运行会有 SmartScreen 提示
- 修改 `config.toml` 后需要重启；Lua 脚本支持热重载
- 多 topic 403 降级、Toast `Tag/Group` 替换、安装包暂未实现
- 勿扰 / 专注助手开启时横幅会被系统抑制，通知仍会进入通知中心
- 当前只提供 Windows amd64 构建

校验文件见 `SHA256SUMS`。
